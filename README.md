# 🏦 Bank Marketing Campaign Response Prediction

An end-to-end machine learning application that predicts whether a customer will respond positively to a targeted bank marketing campaign using customer demographics, financial information, campaign details, and previous campaign interaction data.

🚀 **Live Demo:** https://akhlaque03-bank-marketing-campaign-response-prediction.streamlit.app/
